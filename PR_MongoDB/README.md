# Практична робота: Встановлення та базова робота з NoSQL базою даних MongoDB
**Виконав:** Кузьмін Артур

## ❓ Контрольні питання

1. **Що таке NoSQL база даних?**
   NoSQL (Not Only SQL) — це нереляційна система керування базами даних, яка зберігає інформацію не у вигляді жорстких таблиць зі зв'язками, а у гнучких форматах (документи JSON/BSON, пари «ключ-значення», графи або колонки). Вона легко масштабується горизонтально та підходить для неструктурованих або швидкозмінних даних.

2. **Що таке документ у MongoDB?**
   Документ — це базова одиниця зберігання даних у MongoDB (аналог рядка в SQL-таблиці). Він представляє собою набір пар «ключ: значення» у форматі BSON (бінарний JSON) і може містити вкладені об'єкти та масиви.

3. **Що таке колекція?**
   Колекція — це група документів у базі даних MongoDB (аналог таблиці в реляційних БД). На відміну від SQL-таблиць, колекція не вимагає суворої єдиної схеми: документи всередині однієї колекції можуть мати різний набір полів.

4. **Чим MongoDB відрізняється від SQL?**
   - **Модель даних:** MongoDB зберігає гнучкі JSON/BSON-документи, а SQL — структуровані таблиці з рядками та стовпцями.
   - **Схема:** MongoDB має динамічну схему (можна додавати нові поля окремим документам без зміни всієї структури), тоді як SQL вимагає заздалегідь визначеної схеми таблиць.
   - **Зв'язки та масштабування:** у MongoDB замість складних `JOIN`-запитів часто використовують вкладені документи та масиви, а також вона простіше масштабується горизонтально (шардинг).

5. **Для чого використовується `find()`?**
   Метод `find()` використовується для пошуку та вибірки документів із колекції за заданими критеріями фільтрації (аналог `SELECT` в SQL). Якщо викликати `db.collection.find()` без параметрів, він поверне всі документи колекції.

## 🏁 Висновок
У ході практичної роботи було встановлено та запущено сервіс NoSQL СУБД MongoDB на Ubuntu, створено базу даних `students_db` та колекції `students` і `courses`. Опановано базові та розширені CRUD-операції (`insertOne`, `insertMany`, `find`, `updateOne`, `deleteOne`), фільтрацію за операторами (`$gt`, `$gte`), сортування (`sort`) та роботу зі складними документами, що містять масиви й вкладені об'єкти.
