=== Опис ===
Схема: браузер -> Nginx (порт 8080, wp-lb.conf) -> Apache (порт 80, wordpress-prod.conf, домен wp.prod.local) -> WordPress -> MariaDB.
Production-база даних: wp_prod, користувач wp_prod_user (права лише на цю БД). Дані перенесено зі старої БД через SQL-дамп, siteurl і home змінено на http://wp.prod.local:8080.
Права wp-config.php: власник www-data, режим 640. Файл і SQL-дампи у Git не додаються.
Резервну копію wp_prod створено командою mariadb-dump (файл wp_prod_backup.sql, зберігається в ~/wp_backups).
Nginx працює як reverse proxy з одним Apache backend, це не повноцінне балансування навантаження.
