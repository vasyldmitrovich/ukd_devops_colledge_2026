# Практична робота: Встановлення та базова робота з MariaDB

## Виконані завдання
- Встановлено та перевірено сервіс `mariadb-server` в Ubuntu 22.04.
- Створено базу даних `students_db` та таблиці `students` і `courses`.
- Виконано операції додавання (`INSERT`), вибірки (`SELECT`), фільтрації (`WHERE`), сортування (`ORDER BY`), оновлення (`UPDATE`) та видалення (`DELETE`) даних.
- Налаштовано зв'язок між таблицями за допомогою зовнішнього ключа (`FOREIGN KEY`) та виконано об'єднану вибірку (`INNER JOIN`).

## Пояснення: різниця між таблицями та зв’язками
- **Таблиця** — це основна структура для зберігання однотипних даних про певну сутність (окремо про студентів у `students` та окремо про навчальні предмети у `courses`).
- **Зв’язок (Relationship)** — це логічне поєднання між таблицями за допомогою ключів (`PRIMARY KEY` та `FOREIGN KEY`), яке дозволяє пов'язувати записи між собою та уникати дублювання інформації.

## Відповіді на контрольні питання
1. **Що таке реляційна база даних?** — Це база даних, у якій інформація зберігається у вигляді взаємопов’язаних двовимірних таблиць (відношень).
2. **Що таке таблиця?** — Це об'єкт реляційної БД для зберігання структурованих даних про певну сутність, що складається зі стовпців (полів) та рядків (записів).
3. **Що таке PRIMARY KEY?** — Первинний ключ; унікальний ідентифікатор кожного рядка в таблиці, який не може повторюватися та містити значення `NULL`.
4. **Для чого потрібен SELECT?** — Оператор `SELECT` використовується для читання (вибірки) даних із таблиць бази даних, їх фільтрації, сортування та об'єднання.
5. **Що таке FOREIGN KEY?** — Зовнішній ключ; поле в одній таблиці, яке посилається на `PRIMARY KEY` іншої таблиці, забезпечуючи зв'язок і посилальну цілісність даних.
