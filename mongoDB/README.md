# Практична робота: MongoDB

- Встановлено MongoDB 4.4 на Ubuntu 22.04 (VM, Vagrant)
- База: students_db, колекції: students, courses
- Команди: queries.js
- Дамп бази: dump/

## Контрольні питання
1. NoSQL - бази без табличної реляційної моделі, з гнучкою схемою.
2. Документ - запис у форматі JSON/BSON з парами поле: значення.
3. Колекція - група документів, аналог таблиці в SQL.
4. Відмінність від SQL: немає жорсткої схеми та JOIN, дані зберігаються як документи.
5. find() - вибирає документи з колекції за фільтром.
